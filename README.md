# iPhone 16 Pro — 3D Patent Blueprint Exploded View

An interactive 3D CAD / patent-blueprint exploded teardown showcase of **iPhone 16 Pro** rendered in a pure warm-beige drafting paper & black hidden-line ink aesthetic using **Vite + React + TypeScript + Three.js**.

## Highlights

- **Pure Monochrome Patent Aesthetic**: Warm beige drafting paper (`#E9E0CF`) with procedural grain, custom GLSL Hidden-Line Removal (HLR) shader with toggleable architectural pen cross-hatching, constant-width screen-space silhouette outlines, and monochrome blueprint scan-wave sweep.
- **11 Anatomically Accurate Procedural CAD Layers**:
  1. Ceramic Shield Front Glass & Super Retina XDR OLED
  2. TrueDepth & Dynamic Island Sensor Array
  3. Grade 5 Titanium Chassis & Aluminum Thermal Substructure (with Action, Volume, Power & Sapphire Camera Control buttons)
  4. A18 Pro Dual-Stack Logic Board & PCB Traces
  5. Pro Triple-Camera System (with telescoping 48MP multi-element lens stack & 5× Tetraprism folded optics)
  6. Laser-Welded Steel-Cased L-Shaped Battery
  7. Taptic Engine Linear Actuator
  8. Bottom Stereo Speaker & 24-Pin USB-C Assembly
  9. MagSafe 18-Magnet Array & 11-Turn Qi2 Spiral Charging Coil
  10. Textured Matte Rear Glass & Sculpted Camera Plateau
  11. Micro-Fasteners (P2 Pentalobe Screws, Y000 Screws, Brackets & IP68 Seal Gasket)
- **24 Anti-Colliding Engineering Annotations**: 11 primary bilingual patent callouts + 13 micro-detail pins + live 3D architectural dimension brackets (`149.6 mm`, `71.5 mm`, and stretching `ΔZ` depth track).
- **Show-Off Interactive Controls**:
  - Wheel scrub / Cursor horizontal scrub / Vernier caliper slider
  - Staggered wave explosion choreography
  - Auto Showcase cinematic orbit mode (`▷ 自动巡航`)
  - Blueprint ink scan sweep (`S`) & Pure Stage presentation mode (`H`)
  - Click any component or BOM index item to fly-to & inspect specs (`ESC` to reset)
